# Watchdog

The watchdog is optional supervision infrastructure. It can inspect main or child activity for missed constraints, correctness risks, unsafe changes, loops, and scope drift. It is separate from configured child agents and does not select or launch an agent profile.

Configure cadence, model, thinking, permissions, and per-agent exceptions explicitly in settings. Per-agent keys match identities that you installed; their spelling has no built-in meaning.

Use watchdog management actions to inspect and configure runtime/session/user/project policy. The package does not enable a role workflow merely because an agent has a familiar name.
