## Absence interpretation

The card's literal `rg` command reports many `async` matches because retained JavaScript/TypeScript correctly uses `async` functions; these are syntax, not the removed public field/background product. It also reports the intentional negative boundary probes (`async`, `workflowScript`) and the final-proof regex itself. `docs` is absent, so including that path emits a harmless missing-path diagnostic. The automated proof therefore uses semantic removed identifiers for retained production source, forbidden legacy directory/path checks, an exact package whitelist, and ordinary validation tests for removed fields. This preserves legitimate negative documentation and does not confuse language syntax with product residue. No legacy fixture-prose exclusion is needed because those fixtures are deleted.
